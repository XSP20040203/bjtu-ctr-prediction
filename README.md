# 北京交通大学广告点击率预测：最佳整合方案归档

本仓库保存熊舒鹏（机械与电子控制学院）的广告点击率预测大作业。归档对象是 **2019 年 11 月 17 日平台反馈 AUC 为 0.81635 的最终整合方案**，包括它用到的模型组件、原始数据、代码、最终提交、Word 报告、学术 PPT 和模型结构网页。

0.81635 来自用户反馈的平台成绩。本地没有 17 日广告真实标签；本次整理没有读取或打包 17 日反推标签，没有重新训练或调整模型。15、16 日反复参与开发，其成绩属于开发结果。

| 数据日期 | 结果 | 含义 |
|---|---:|---|
| 2019-11-15 | 0.8023895973270289 | 保存的完整开发日预测 AUC |
| 2019-11-16 | 0.8140787742362926 | 最终冻结方案的完整开发日 AUC |
| 2019-11-17 | **0.81635** | 用户反馈的平台 AUC |

## 下载完整模型和数据

请打开本仓库的 **Releases → 最佳整合模型 0.81635**，下载所有 `best-model-081635.tar.zst.*` 分卷，以及 `bundle-manifest.json`、`SHA256SUMS.txt`。仓库为私有，需要登录有访问权限的 GitHub 账号。

源代码、报告、PPT、结构网页和最终提交可在 `project/` 内直接浏览。原始 CSV、模型权重和数值缓存保存在 Release 完整包内。

已登录 GitHub CLI 时，也可以运行：

```powershell
gh release download best-model-081635-20261104 --repo XSP20040203/bjtu-ctr-prediction --dir downloads
python -m pip install zstandard==0.25.0
python restore_best_bundle.py --parts downloads --output restored
```

工具会先核对全部分卷，再逐个校验文件的 SHA256，恢复到 `restored/大作业上传/`。无需手动合并分卷。只检查压缩包时加 `--verify-only`。

## 模型用大白话怎么理解

模型先把用户资料、广告属性和历史点击/关闭列表变成数值特征，再让不同的神经网络和树模型分别判断点击倾向。随后，用户当天的整体活跃程度、广告受众特征、新闻行为、历史反馈和分组排序模块逐步修正基础预测。最后一个模块专门处理历史曝光较少的广告。

最后一层接收 **395 维上下文特征 + 6 维历史相似度 = 401 维输入**。6 维历史相似度分别对应三类点击历史和三类关闭历史与当前广告的关系。保存的 CatBoost 模型深度为 6、共有 2400 棵树；最终按冻结的 0.1 权重融合，并仅对历史曝光不超过 100 条的广告生效。17 日有 84591 条记录满足这个条件。

完整的各模块名称、维度及连接方式见 Word 的《整合模型结构与维度详解》、PPT 和结构网页。

## 独立复放最后一层

使用 Python 3.10 或 3.11。提供的 `replay_best_final_stage.py` 用保存的前级预测、401 维冻结输入和已选中权重，重新计算最后一次修正，并核对模型原始分数、最终概率及 CSV 哈希。这是**固定前级预测上的末端复放**；本次没有执行所有历史脚本，也没有声称已在新环境从原始数据完整重跑所有前级模块。

```powershell
python -m pip install -r requirements-final-replay.txt
python replay_best_final_stage.py --project "restored/大作业上传" --output replayed17
```

`--output` 必须是新目录，避免覆盖已有提交。实际验证结果见 `archive/final-stage-replay-verification.json`。原项目部分旧脚本使用绝对路径，并包含已停用的反推评估流程，仅保留作配方与来源追溯；请使用上面的独立入口复放。

最终提交共 **404182 行**，列为 `id,pctr`，`id` 按原始数据行序从 0 开始。SHA256：

```text

```
